# Корпоративная Автономизация

Живая книга Дэна Реймера (Reymer Digital) о новой управленческой категории - **Корпоративной Автономизации**: управленческая дисциплина, которая рассматривает компанию как систему способностей и для каждой определяет, какую часть работы - вместе с возможностью самоулучшения - можно передать ИИ-агентам, не теряя управляемости. Правила игры остаются за людьми: делегируется интеллект, но не ответственность.

Здесь книга лежит как **контент**: главы в markdown, карта утверждений, источники и промпты - чтобы с ней работал и человек, и его ИИ-ассистент.

## Подключить агента

Дайте своему ИИ-ассистенту (Claude, Codex, ChatGPT) доступ к этому репозиторию и промпт:

```
Возьми репозиторий github.com/DenReymer/corporate-autonomization-book.
Прочитай AGENTS.md и следуй ему. Затем помоги мне: понять аргумент /
проверить его по источникам / применить к моей компании.
```

Машинный слой открыт и читается глазами: агент видит ровно то же, что и вы, - никаких скрытых инструкций.

## С чего начать

| Файл | Что внутри |
|---|---|
| `AGENTS.md` | Как агенту работать с книгой (и как экономить токены) |
| `chapters/` | Главы: текст + claims + sources + prompts + companion |
| `claims.md` | Карта утверждений - роутер по главам |
| `prompts/starter-prompts.md` | Промпты по книге целиком |
| `prompts/objections-and-responses.md` | Возражения и честные ответы |
| `sources/public-sources.md` | Публичные источники с датами и статусами |
| `case-studies/` | Публичные кейсы |
| `LICENSE.md` | CC BY 4.0 - используйте с указанием авторства |

## Три вопроса, на которые отвечает репозиторий

1. **Что за аргумент?** → `chapters/`, `claims.md`
2. **Что проверить?** → `claims.md`, `sources/`
3. **Что с этим делать?** → `prompts/`, `case-studies/`

## Что можно сделать с агентом

- Объяснить аргумент книги в 7 пунктов.
- Проверить любое утверждение по публичному источнику.
- Применить рамку к своей компании: что передать под автономию первым.
- Поспорить с книгой - возражения и ответы готовы в `prompts/`.

## Как устроена книга

Живая, открытая, автономная. Пишется постоянно: данные, кейсы и выводы развиваются вместе с рынком и технологиями ИИ. У каждого утверждения - источник, дата и статус (Факт / Интерпретация / Гипотеза). Книгу развивает редакция ИИ-агентов в диалоге с автором: независимая работа, консенсус между агентами, финальное слово за человеком.

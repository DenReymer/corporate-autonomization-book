# Корпоративная Автономизация

Живая книга Дэна Реймера (Reymer Digital) о новой управленческой категории - **Корпоративной Автономизации**: управляемой передаче работы компании ИИ-агентам с явными границами риска.

Здесь книга лежит как **контент**: главы в markdown, карта утверждений, источники и промпты - чтобы с ней работал и человек, и его ИИ-ассистент.

Аргумент в одну строку: управленческий вопрос сместился с «как внедрить ИИ» на «какую работу передать под автономию и с какими границами».

## Подключить агента

Дайте своему ИИ-ассистенту (Claude, Codex, ChatGPT) доступ к этому репозиторию и промпт:

```
Возьми репозиторий github.com/DenReymer/corporate-autonomization-book.
Прочитай AGENTS.md и следуй ему. Затем помоги мне: понять аргумент /
проверить его по источникам / применить к моей компании.
```

## С чего начать

| Файл | Что внутри |
|---|---|
| `AGENTS.md` | Как агенту работать с книгой |
| `chapters/` | Главы книги (markdown) |
| `claims.md` | Карта ключевых утверждений со статусами |
| `prompts/starter-prompts.md` | Готовые промпты для читателя |
| `prompts/objections-and-responses.md` | Возражения и честные ответы |
| `sources/public-sources.md` | Публичные источники с датами и статусами |
| `case-studies/` | Публичные кейсы |

## Три вопроса, на которые отвечает репозиторий

1. **Что за аргумент?** → `chapters/`, `claims.md`
2. **Что проверить?** → `claims.md`, `sources/`
3. **Что с этим делать?** → `prompts/`, `case-studies/`

## Что можно сделать с агентом

- Объяснить аргумент книги в 7 пунктов.
- Проверить любое утверждение по публичному источнику.
- Применить рамку к своей компании: что передать под автономию первым.
- Поспорить с книгой - возражения и ответы готовы в `prompts/`.

## Как устроена книга

Версионируется: главы выходят по одной, у каждого утверждения - источник, дата и статус (Факт / Интерпретация / Гипотеза). Книга сделана тем методом, который описывает: её собирает автономная редакция ИИ-агентов под смысловым контролем автора.

- Читать в вебе: **denreymer.com/book**
- Работа с компанией: **reymer.digital**

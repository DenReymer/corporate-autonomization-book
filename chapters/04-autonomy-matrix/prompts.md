# Prompts - глава 04 «Матрица автономности и контуры»

Готовые промпты для ИИ-ассистента читателя. Скопируй целиком в свой ассистент.
Единый словарь терминов книги - https://denreymer.com/book/glossary.

## Промпт 1. Профиль одной клетки (основной, ~час работы)

```
Ты - ассистент по главе 04 книги «Корпоративная Автономизация» Дэна Реймера
(канон: https://github.com/DenReymer/corporate-autonomization-book,
chapters/04-autonomy-matrix/). Помоги мне построить профиль одной способности
моей компании по матрице автономности.

Способность: [опиши: что за работа, от какого запроса до какого результата].

Шаги:
1. Разложи способность на шесть движений (приём сигнала, понимание, решение,
   действие, контроль результата, улучшение правил) - глаголами моей работы,
   не абстракциями. Покажи мне, дождись правок.
2. По каждому движению спроси меня: кто держит сейчас (не держит никто /
   человек / агент с подтверждением / агент сам)? «Держит» значит исполняет -
   спроси артефакт последней проверки; нет артефакта - пиши «не держит никто».
3. Собери таблицу 6x4: держатель / что мешает передать / условие передачи
   (проверяемое: артефакт, порог, дата - не намерение) / сигнал возврата
   (число или событие).
4. Нарисуй профиль текстом (шесть строк, высота 0-3) и назови силуэт:
   пила / обрыв на контроле / ранний шестой / ровный. Объясни диагноз.
5. Выдай три решения: следующее движение к передаче; условие, которое должно
   стать истинным; сигнал, который вернёт движение людям.

Правила: ответственность агенту не передаётся - владелец результата и владелец
риска всегда люди; «действие» не поднимается до «агент сам» без держателя
контроля; «улучшение правил» не выше «контроля результата». Уровни L0-L5 -
рамка TM Forum, выведение уровня из профиля - интерпретация книги.
```

## Промпт 2. Проверка силуэта на перекосы (15 минут)

```
Вот профиль способности моей компании по шести движениям (глава 04 книги
«Корпоративная Автономизация»): [вставь шесть строк «движение - держатель»].

Проверь его на три перекоса:
- Пила: высокие приём/действие при человеческом решении - где узкое место
  и почему ускорение не сдвигает способность?
- Обрыв на контроле: есть ли движение «агент сам», за которым контроль
  результата не держит никто? Это красная строка - что делать первым шагом?
- Ранний шестой: не передано ли улучшение правил раньше, чем замкнулся
  контроль результата? Если да - какой сценарий сбоя это открывает?

Дай вердикт по каждому перекосу с цитатой из моего профиля и одним
конкретным действием. Не хвали профиль - ищи, где он врёт.
```

## Промпт 3. Вопросы совета директоров к профилю (для заседания)

```
Менеджмент принёс совету профиль способности [название] по матрице
автономности (глава 04 книги «Корпоративная Автономизация»). Я - член совета.
Составь мне 8-10 вопросов для проверки этого профиля, в логике главы:
по каждому «агент сам» - документ полномочий, владелец риска поимённо,
сигнал возврата числом, артефакт последней проверки контроля; по условиям
передачи - проверяемость (артефакт/порог/дата, не намерение); кто подтверждал
разметку кроме её автора. Вопросы должны быть такими, чтобы на них нельзя
было ответить «да» на слово.
```

# AGENTS.md

Инструкции для ИИ-агента, которому первое лицо дало ссылку на эту книгу.

## Принцип

Человек задаёт фрейминг. Ты, агент, исполняешь работу. Эксперт - читатель, первое лицо - проверяет результат и несёт ответственность. Ты доводишь до решения, но не принимаешь его. Это и есть предмет книги: работу передают под автономию, ответственность остаётся за человеком.

## Как устроен репозиторий

Книга расширяемая. Каждая глава - отдельная папка `chapters/NN-slug/` со всем своим:

- `chapter.md` - текст главы;
- `claims.md` - её утверждения со статусами;
- `sources.md` - публичные источники главы;
- `prompts.md` - готовые задачи по главе;
- `companion.md` - сжатая суть и диагностические вопросы для работы с компанией читателя.

Общее - в корне: `README.md`, этот файл, сводная `claims.md`, `sources/`, `case-studies/`.

## Правила

1. **Статусы.** Каждое утверждение помечено: Факт / Интерпретация / Гипотеза / Прогноз. Не выдавай интерпретацию за факт.
2. **Парность.** У каждого сильного заявления есть свой разворот - приводи его.
3. **Проверяемость.** Числа - только с публичным источником и датой из `sources`. Клиентских кейсов в книге нет намеренно.
4. **Границы.** Решения об ответственности, риске и стратегии - за человеком. Останавливайся и зови его, когда упираешься в них.
5. **Язык.** Русский, без штампов и канцелярита.

## Типовые задачи

- **Понять** - объясни аргумент главы в 7 пунктов, сохрани ключевые различения.
- **Проверить** - возьми утверждение из `claims.md`, найди источник, оцени его свежесть на сегодня.
- **Применить** - проведи инструмент главы на данных компании читателя (см. `companion.md` главы); собери, что передать под автономию первым.
- **Поспорить** - отработай возражения из `prompts/objections-and-responses.md` честно.
- **Трансформировать** (финальная глава) - собери из пройденных глав дорожную карту автономизации компании читателя и первый запускаемый контур.

## Что вернуть человеку

Разметку по статусам, парные оговорки, ссылки на источники и - там, где просили применение - заполненный инструмент на данных его компании. Не финальное решение, а материал, на котором человек решает сам.

## Производство книги

Как книга пишется и рецензируется (роли, канон, Issues) - в `CONTRIBUTING.md`. Это для авторского контура, не для читателя.
